# Sales Customer Analytics Dashboard

This project presents an interactive **Sales and Customer Analytics Dashboard** developed using Tableau to help stakeholders analyze business performance, customer behavior, and sales trends.

The project is designed as a portfolio project showcasing:

* Business intelligence dashboard development
* Sales and customer analytics
* Interactive KPI reporting
* Data visualization and dashboard storytelling

---

## Dashboard Overview

The project contains two primary dashboards:

1. **Sales Dashboard**
2. **Customer Dashboard**

---

## Project Objectives

### Sales Dashboard

Analyze sales performance through:
- Total Sales analysis
- Total Profit analysis
- Total Order Quantity analysis
- Monthly sales trend analysis
- Product subcategory comparison
- Weekly sales and profit trends
- Year-over-year KPI comparison

### Customer Dashboard

Analyze customer behavior and engagement through:
- Total customer analysis
- Total Sales per customer analysis
- Total Order volume analysis
- Customer trend analysis
- Customer order distribution
- Top 10 customers by profit
- Historical customer performance tracking

---

## Dashboard Features

### KPI Cards (BANs)
- Total Sales
- Total Profit
- Quantity Sold
- Total Customers
- Sales per Customer
- Total Orders

### Charts & Visualizations
- Dual Line Charts
- Circle Charts
- Bar-in-Bar Charts
- Bar Charts
- Histogram Charts
- Text Tables
- Weekly Trend Charts

### Interactivity
- Dynamic year selection
- Cross-dashboard navigation
- Interactive chart filtering
- Product and location filters

### Filters
- Category
- Subcategory
- Region
- State
- City
